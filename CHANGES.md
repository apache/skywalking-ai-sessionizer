# Changes by Version

The changelog lives in the documentation, one page per version, and is published with the docs on
the SkyWalking website.

- [Current version, in development](docs/en/changes/changes.md)

Released versions are listed under Changelog in [`docs/menu.yml`](docs/menu.yml) as they are
released. The text for a GitHub release page is produced from the version's page with
`make release-notes VERSION=<version>`.
